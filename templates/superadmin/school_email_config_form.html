Configuration Help
SMTP Setup

Configure custom mail server or Google Workspace SMTP.

  • Host: e.g. smtp.gmail.com
  • Port: 587 (TLS) or 465 (SSL)
  • Use an App Password if 2-Step Verification is active
SendGrid Setup

High-deliverability cloud transactional email.

  • Create an API Key with "Full Access" or "Mail Send"
  • Verify Single Sender or Domain Authentication in SendGrid
Mailgun Setup

Developer-friendly email API service.

  • Copy Primary Account API Key from Mailgun settings
  • Use your verified sending domain (e.g. mg.school.com)
Amazon SES Setup

AWS Simple Email Service for institutional scale.

  • Create an IAM user with ses:SendEmail policy
  • Verify sending domain identity in AWS SES Console
Postmark Setup

Fast transactional email service.

  • Copy Server API Token from your Postmark Server
  • Verify sender email address or domain DKIM records

Select an Email Provider on the left to see provider-specific setup instructions.

Email Best Practices
  • Always use encrypted connections (TLS/SSL)
  • Verify SPF and DKIM records on your school domain to prevent emails from landing in spam
  • Set realistic daily limits to safeguard sender reputation
  • Ensure From Email matches the authenticated sending domain

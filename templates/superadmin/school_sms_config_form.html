Configuration Help
MobileSasa Instructions

MobileSasa provides high-speed SMS delivery across East Africa with approved Sender IDs.

  • Register an account at mobilesasa.com
  • Generate an API Token from your Developer portal
  • Request and register an approved alphanumeric Sender ID
Twilio Instructions

Twilio provides worldwide SMS infrastructure with real-time delivery logs.

  • Retrieve Account SID and Auth Token from the Twilio Console
  • Use your active Twilio phone number in E.164 format (e.g. +1234567890)
  • Ensure outbound SMS permissions are enabled for destination countries
Africa's Talking Instructions

Direct telco connections optimized for African educational institutions.

  • Obtain your API Key and Username from africastalking.com
  • Configure custom Alphanumeric Sender ID on your dashboard
  • Top up your account balance for active SMS sending
Infobip Instructions

Global cloud communication with dedicated carrier routes.

  • Copy API Key and custom Base URL from your Infobip account
  • Set the registered sender name or numeric sender ID
Clickatell Instructions

Enterprise-grade SMS delivery platform.

  • Generate API Key from Clickatell portal
  • Use default base URL: https://platform.clickatell.com
Vonage (Nexmo) Instructions

Global messaging API by Vonage.

  • Copy API Key and API Secret from Vonage dashboard
  • Ensure account has adequate credit balance

Select an SMS Provider on the left to see specific configuration instructions and guidelines.
